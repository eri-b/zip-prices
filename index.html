READING THIS MAP

A ZIP code is not a neat polygon.

Outlined areas are 2020 Census ZIP Code Tabulation Areas (ZCTAs): public approximations of USPS ZIP geography. Some USPS ZIPs have no matching ZCTA and therefore cannot be hovered as an area.

When supplied, route counts come from USPS Population Mobility Trends and represent change-of-address requests. The product publishes only leading routes above its thresholds. Shown routes are therefore not a complete count of moves, and they are separate from IRS tax-return migration data.

The local CSV stays in your browser during this session. Check your USPS license before publishing derived counts. Data sources and import details ↗
